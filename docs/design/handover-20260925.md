## 3. 本轮发现并修复的新问题：前端编译中断

两个修复 agent 因额度中断，`app/src/ui/ChatView.tsx` 停在半改状态，`tsc` 报 5 个错误，其中 4 个是**作用域内根本不存在的标识符**（运行时 `ReferenceError`，不只是类型问题）：

- `const historyInflight = new Map<string, Promise<void>>()` 却按 `Set` 使用（`.add/.has/.delete`）→ 改为 `new Set<string>()`。
- `upsertMessage`（3 处）与 `prependMessages`（1 处）在初始历史加载与 `loadMore` 分页里被调用，却没有从 `../store` 导入 → 补进导入。

这两处缺失会让“打开会话拉历史”和“上滑分页”直接抛错。Vitest 当时仍然全绿，因为 esbuild 只剥类型、这些分支未被用例覆盖——**单测通过不能替代 `npm run build`**。修复后浏览器冒烟已实测该路径正常。

## 7. 复验命令矩阵（从零重跑）
