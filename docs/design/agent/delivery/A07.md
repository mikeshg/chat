## 2. 接口契约

无新表。`agents.runtime` 仍是 jsonb，多一种合法形状。

### REST

- `GET /v1/agent-hosts/{id}/registry` → 200 `{"entries":[{id,name,version,description,icon,kinds,status,reason}],"error":null|string}`。宿主离线 409 `host_offline`。不是自己的宿主、或不存在 → 404。宿主 20 秒没回 → 504 `registry_timeout`。登记表拉失败且没有缓存时仍是 200，`entries` 为空，`error` 说明原因。
- `POST /v1/agent-hosts/{id}/registry/{entry_id}/install`，正文 `{"version":"..."}` → 202 `{"ok":true}`。离线 409，别人的宿主 404，id / version 不合法 400 `bad_runtime`。
- `POST/PATCH /v1/agents` 的 `runtime`：`{"command","args"}` 或 `{"registry":{"id","version"}}`。登记表只查格式，不访问登记表。

`status`：`ready` / `installable` / `unsupported`。`kinds`：条目实际带的分发方式，顺序是 `npx`、`uvx`、`binary`。一种条目可以多种分发，列表状态取最好的：已可用优于可安装，可安装优于不支持。

### WS

宿主：

- 服务端 → 宿主 `{"type":"registry_list","request_id"}`
- 宿主 → 服务端 `{"type":"registry_result","request_id","entries":[...],"error"?}`
- 服务端 → 宿主 `{"type":"registry_install","request_id","entry_id","version"}`
- 宿主 → 服务端 `{"type":"registry_install_progress","entry_id","stage","error"?}`

主人的普通连接：同一帧名，多一个 `host_id`。`stage` 用中文：`下载`、`校验`、`解压`、`完成`、`失败`。没有 sha256 的 binary 不发 `校验`。npx 安装发 `下载` 然后 `完成` 或 `失败`。

调用失败时 `invocation_finish.error` 为 `registry_not_installed`，服务端记成 `failed` / 该错误码。

### 宿主安装位置

- npx：`npm install --prefix <数据目录>/agents/npm/<id>@<version> <package>@<version>`，启动 `node_modules/.bin` 里该包的 bin（读安装后的 `package.json`）。
- binary：下载 `archive`，有 sha256 就校验，按扩展名解 zip / tar.gz 到 `<数据目录>/agents/bin/<id>/<version>/`，启动相对该目录的 `cmd`。
- uvx：本机有 `uvx` 即 `ready`，不单独安装。启动 `uvx`，登记表没给 args 时用 `<package>@<version>`。
- 同时能装 binary 和 npx 时，先装当前平台的 binary。

几种分发都不可用时的原因：没有 Node.js 是「需要先安装 Node.js」，没有 uv 是「需要先安装 uv」，当前平台没有 binary 键是「当前系统没有对应的安装包」。

## 4. 未覆盖项与已知限制

- 真 agent 冒烟没有跑。本机没有要求登录 Claude Code / Codex。测试在 `agent-host/tests/smoke.rs`，不设环境变量就跳过。
- 跑法（需要本机已登录 Claude Code 和 Codex，并且 PATH 上有 Node.js；登记表条目若是 npx，测试会装到临时数据目录）：

  ```
  CHAT_REAL_AGENT_SMOKE=1 cargo test -p agent-host --test smoke -- --nocapture --test-threads=1
  ```

  每个适配器发「只回复 pong」和「在当前目录创建文件 smoke.txt」。权限请求按现在的规则拒绝，并断言拒绝次数 ≥ 1。id 从登记表里按名字匹配 Claude / Codex，不写死。
- 504 没有集成测试：要等满 20 秒且宿主故意不回。实现是超时摘掉 oneshot 并返回 `registry_timeout`。
- 不自动更新已装版本，没有 preview 渠道，不能卸载。
- 编辑页的「登记表：名称 版本」由组件在宿主在线时向登记表查名称，离线时退回 id。浏览器实测没有点开编辑页。
