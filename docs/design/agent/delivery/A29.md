# A29 交付

## 1. 实现摘要

- `agent-host/Cargo.toml`：新增任务单允许的四个依赖（`agent` v0.1.0 git tag、`schemars`、`async-trait`、`regex`），无其他新增。
- `agent-host/src/builtin/mod.rs`：内置 agent 的进程入口 `run_stdio()` 与 stdio NDJSON JSON-RPC 通道 `Rpc`（出站请求 pending 表、写锁串行化、`session/update` 通知助手）。stdout 只走协议帧，日志写 stderr。
- `agent-host/src/builtin/acp_server.rs`：ACP 服务端。实现 `initialize`（声明 `loadSession`、`promptCapabilities.image`、`mcpCapabilities.http`）、`session/new`（端点为空报「管理员还没有配置模型」，返回 `models` 不返回 `modes`）、`session/load`（读存档、先回放历史再回响应）、`session/set_model`、`session/prompt`（`stopReason`：`end_turn`/`max_turn_requests`/`cancelled`/`refusal`，模型错误回 JSON-RPC error）、`session/cancel`。每会话一个底座 `Agent`（`turn_limit` 50、固定中文系统提示含 cwd 与操作系统），`AgentEvent` 翻成 `session/update`；`PermGate` 钩子对**每个**工具调用先发 `session/request_permission`（options：allow_once/allow_always/reject_once，allow_always 按 kind+locations 会话内记忆；reject/cancelled → `BeforeTool::Block`「用户拒绝了这次操作」）。模型 id 按第一个 `/` 切成「端点/模型」，空或找不到回退第一个端点第一个模型；`chat`→`OpenAiChat`（`echo_reasoning(true)`），`responses`→`OpenAiResponses`。prompt 内容块：text 拼进 user 文本，image 块写占位「[图片：…，当前模型不可见]」，resource_link/resource 块把路径写进文本。
- `agent-host/src/builtin/tools.rs`：六个工具 `read_file`/`list_dir`/`grep`/`write_file`/`edit_file`/`shell`。相对路径按会话 cwd 解析；输出 30000 字符截断并注明；read_file 带行号 + offset/limit + 二进制报错；list_dir depth 1..=5 跳过 `.git`/`node_modules`/`target`；grep 正则 + `*.ext` 后缀过滤、上限 200 条、`文件:行号: 内容`；edit_file 的 `old` 不唯一时报错、`replace_all` 全替；shell 走 `cmd /C`/`sh -c`、合并 stdout+stderr + 退出码、默认 120s 上限 600s、超时杀进程树（Unix 进程组，Windows `taskkill /T /F`）。`write_file`/`edit_file`/`shell` 标 `exclusive()`。`describe()` 统一产出 ToolStart 与权限卡片用的 title/kind/locations（文件类填解析后绝对路径，shell 填 cwd，注入工具记 `other`）。
- `agent-host/src/builtin/mcp_client.rs`：`mcpServers` 里 `type:"http"` 的条目逐个 `initialize`→`tools/list`，工具包成 `<服务名>__<工具名>`（schema 原样），调用走 `tools/call`；用宿主既有 reqwest 0.12，JSON-RPC over POST 无 SSE。单服务连不上记 stderr 跳过，不拖垮会话。
- `agent-host/src/builtin/store.rs`：会话存档 `<state_dir>/<session-id>.json`（`{model, transcript}`；写临时文件再 rename；id 消毒挡路径穿越）。每次 `RunEnd` 后落盘。
- `agent-host/src/bin/chat-builtin-agent.rs`：bin 目标，`run_stdio()` 薄壳。
- `agent-host/src/runtime.rs`：`AgentSpec.builtin: Option<Value>`；`from_json` 识别 `runtime.builtin == true`，此时 command/args 允许为空。
- `agent-host/src/conn.rs`：`materialize` 对内置 agent 取 `HostConfig.builtin_agent`（None → 「这台电脑不支持内置 agent」），注入 `CHAT_BUILTIN_ENDPOINTS`（快照 `builtin.endpoints` 原文）与 `CHAT_BUILTIN_STATE_DIR`（`<data_dir>/builtin`）；`probe` 对内置 agent 不起子进程直接回空模型/模式。
- `agent-host/src/lib.rs`：`pub mod builtin`、`HostConfig.builtin_agent`。
- `agent-host/src/acp.rs`：修 `permission_response` 等待审批时把 `cancel` 发送端已丢（`changed()` 返回 `Err`）误判为取消的问题——与 `wait_resp_or_cancel` 同口径改为停止盯取消、只等审批决定。不修的话无连接上下文（库直用路径）里任何超档请求都会被秒拒，本票的「拒绝」用例无法成立。
- `agent-host/examples/host.rs`：`builtin_agent` = 与示例同批编译的 `chat-builtin-agent` 二进制。
- `agent-host/tests/builtin.rs`：本地假 OpenAI Chat Completions 端点（axum 按脚本出 SSE，记录请求体）+ `env!("CARGO_BIN_EXE_chat-builtin-agent")` 经 `run_invocation` 端到端驱动。
- `agent-host/src/conn.rs`、`src/builtin/tools.rs`：单测。
- `app/src-tauri/src/main.rs`：`--builtin-agent` 直接跑 `run_stdio()` 退出，不起窗口。
- `app/src-tauri/src/agent_host.rs`：`builtin_agent` = 当前可执行文件 + `--builtin-agent`。
- `agent-host/tests/{acp,mcp,reconnect,smoke}.rs`、`server/tests/it.rs`：只补 `builtin: None` / `builtin_agent: None` 字段，无行为改动。

## 2. 接口契约

- 无 REST/WS/表结构变更，无迁移。
- `HostConfig` 新增字段 `builtin_agent: Option<(String, Vec<String>)>`（库 API 变更，构造点已全部更新）。
- `AgentSpec` 新增字段 `builtin: Option<Value>`；快照 `runtime.builtin == true` 时解析为 Some（值为快照 `builtin` 字段，A28 契约形状 `{"endpoints":[…]}`）。
- 内置进程环境变量（宿主 → 内置 agent）：
  - `CHAT_BUILTIN_ENDPOINTS`：端点数组 JSON（id/name/protocol/base_url/api_key/models，含 key 原文）。
  - `CHAT_BUILTIN_STATE_DIR`：会话存档目录 `<data_dir>/builtin`。
- ACP 方法面与任务单 §三一致；模型 id 按第一个 `/` 切分（模型名里可再含 `/`）。
- 桌面端程序参数新增 `--builtin-agent`（子进程模式）。

## 4. 未覆盖项与已知限制

- 未做真实模型验证（无 `OPENAI_*`）；DeepSeek 思考链（`echo_reasoning`）与 `responses` 协议路径只有代码路径、没打过真端点。
- image 块只留占位（底座 v0.1 无图片输入）；resource_link/resource 附件以路径文本进模型，模型需自己 `read_file`。
- 未实现 `session/resume` / `session/set_mode` / `authenticate`：只声明 `loadSession`、不返回 `modes`，宿主按声明不会调用；万一被调用回 `-32601`。
- MCP 注入只支持 `http` 形态（宿主看到 `mcpCapabilities.http` 后只会发 http 条目；stdio 桥接条目不会被下发到这里）。
- `allow_always` 只记住「同 kind + 同 locations」，且仅本会话进程内存效。
- 存档为本地明文 JSON（含 transcript），未加密。
- `RunStop` 是 `non_exhaustive`，将来底座新增终态按 `end_turn` 兜底。
