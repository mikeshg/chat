## 4. 未覆盖项与已知限制

- Tauri 壳内 `openUrl` 的端到端点击未实测（本环境只要求 `cargo check`；Web 端 `target=_blank` 路径已实测）。插件失败时回退 `window.open`。
- `tokenize` 是定界符扫描而非完整 Markdown：单行三反引号（`` ```x``` ``）不算代码块（开 fence 行后无换行 → 按文本）；代码块允许行中起始 ```。
- LAN http 部署下 `navigator.clipboard` 可能不可用 → 复制走 `execCommand` 回退，且无论成败都短暂显示「已复制」。
- 链接显示缩短规则为前 36 + `…` + 后 20 字符（任务单只要求中间省略，未规定断点）。
