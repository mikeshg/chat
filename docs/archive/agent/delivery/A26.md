## 1. 实现摘要

- `server/src/agents.rs`：`POST /v1/agents` 在确认电脑属于本人之后，要求这次请求的登录会话就是该电脑当前宿主连接的会话，否则 403 `host_not_local`。
- `server/src/state.rs`：新增 `host_is_local_session`。没有 sid、电脑离线、会话对不上，都不是本机。

## 2. 接口契约

- `POST /v1/agents`：请求体和成功响应不变。新增失败：`403 {"error":"host_not_local"}`。
  - 目标电脑必须当前在线。
  - 该电脑宿主连接的 `HostConn.sid` 必须等于这次 access token 的 sid。
  - token 没有 sid、电脑离线、或登录会话不是这条宿主连接的，都是这个错误。
  - 电脑不存在或不属于本人仍是 404，避免泄露别人的电脑。
- 编辑、删除、探测、定时任务等接口不变。
- 桌面壳新增事件 `agent-host://local-host`，载荷 `{ "host_id": "<uuid>" | null }`。没有新的 REST 或 WS 帧。
- 无迁移。
