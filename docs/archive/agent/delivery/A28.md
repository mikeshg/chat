## 2. 接口契约

### REST

- `GET /v1/admin/settings`：`builtin_endpoints: [{id, name, protocol, base_url, api_key_set, models}]`，不含 `api_key`。
- `PUT /v1/admin/settings`：`builtin_endpoints` 为数组则整体替换：
  - `id` 缺省 / 不是已有端点 id → 服务端生成新 UUID；
  - `api_key` 缺省 → 按 `id` 保留原 key；`""` → 清空；非空 → 覆盖；
  - `name` 1–40；`protocol` ∈ `chat|responses`；`base_url` http/https（去末尾 `/`）；`api_key` ≤500；`models` 去重后 1–50 个、每个 ≤200；端点 ≤20；
  - 违反 → `400 {"error":"bad_builtin_endpoints"}`；非管理员 → 403。
- `GET /v1/agent-builtin/models`：同 `uid()` 使用权闸，无使用权 403；返回 `[{id: "<端点id>/<模型>", name: "<端点名> · <模型>"}]`，不含 `base_url` / `api_key`；模型名本身可再含 `/`（按第一个 `/` 分端点 id 与模型）。
- `POST /v1/agents` / `PATCH /v1/agents/{id}`：`runtime` 接受 `{"builtin": true}`；`{"builtin": false}` → `400 bad_runtime`；`cwd` 等其余校验不变。

### WS / 快照

- `invocation_start.agent` 与 `agent_probe.agent`：仅当 `runtime.builtin == true` 时多一个 `builtin.endpoints`（与存值同形，含 `api_key`），每次调用现读配置；命令 / 登记表快照不带 `builtin`。
- 存储：`server_settings.builtin_endpoints` = 原始 `BuiltinEndpoint[]` JSON 数组。管理员删端点不改 `agents` 行；agent.model 里引用的端点没了，宿主按空 / 默认处理（`id` 第一个 `/` 之后部分匹配不到 → 取第一个端点的第一个模型）。
- 与任务单无偏差。
