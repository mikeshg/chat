# A09 交付

## 2. 接口契约

- `GET /v1/agent-hosts` 不变：`[{id, label, platform, online, last_seen_at}]`。
- 新增 `PATCH /v1/agent-hosts/{id}`，body `{ "label": "…" }`。
  - 先去掉首尾空白，按 Unicode 字符计 1–60。空、纯空白、超过 60 → `400 {"error":"bad_label"}`。
  - 不是自己的宿主，或不存在 → `404 {"error":"host not found"}`。
  - 成功 `200`，body 与列表单条相同（含当时的 `online`）。
- `host_hello` 仍带 `label` / `platform`。第一次插入写入 `label`；冲突时只更新 `platform` 和 `last_seen_at`。
- WS：`agent_host_status` 增加可选 `label`。上下线帧省略该字段；改名帧带新名称，并带当前 `online`。只发给主人的普通连接。旧客户端忽略未知字段。

没有新表、没有迁移。

## 4. 未覆盖项与已知限制

托盘、关窗隐藏、通知只发一次、开机自启的系统注册，无头环境起不了 Tauri 窗口，没有实机点过。主会话可按下面步骤验收：

1. 在 `app` 里用现有的 Tauri 开发命令启动桌面端并登录。
2. 系统托盘出现 Chat 图标。菜单有「显示窗口」「退出」。单击图标应把窗口带到前台。
3. 点窗口关闭按钮：窗口消失，进程还在；第一次弹出通知「Chat 已最小化到托盘，Agent 会继续运行」。再关一次不应再通知。宿主连接不断。
4. 托盘「显示窗口」把窗口打开。托盘「退出」先停宿主（其他客户端看到该宿主离线），然后进程结束。
5. 「我」页有「开机自动启动」，默认关。打开后系统登录项里出现 Chat；关掉后消失。Web 和 Android 看不到这项。
6. 这台电脑第一次成为宿主时，名称是计算机名（拿不到则「桌面端」）。在别的客户端改名后，重启桌面端再连，名称保持改过的值。

Android 目标没有编译。托盘、关窗拦截和自启插件初始化都在 `#[cfg(desktop)]` 里；自启能力文件限定了桌面平台。
